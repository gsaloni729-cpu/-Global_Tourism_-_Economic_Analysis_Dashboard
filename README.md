# Global Tourism & Economic Analysis Dashboard

## 📌 Project Overview

This project presents an **interactive Excel dashboard** designed to analyze **global tourism trends, population metrics, and economic performance (GDP)** across multiple countries, continents, and time periods.

The dashboard combines **tourism, demographic, geographic, temporal, and economic data** to provide insights into seasonal travel patterns, regional tourism distribution, population trends, and GDP performance.

---

## 📊 Key Performance Indicators (KPIs)

| KPI                        |                                          Value |
| -------------------------- | ---------------------------------------------: |
| 🌍 **Total Countries**     |                        **50** unique countries |

## 🗂️ Dataset Schema

The dataset contains demographic, geographical, temporal, tourism, and economic dimensions.

| Field Name     | Data Type | Description                                                             |
| -------------- | --------- | ----------------------------------------------------------------------- |
| **Continent**  | Text      | High-level geographical classification such as Europe, Asia, and Africa |
| **Country**    | Text      | Country associated with the record                                      |
| **Month**      | Text      | Month in which the observation was recorded                             |
| **Seasons**    | Text      | Seasonal classification such as Winter, Spring, Summer, and Fall        |
| **State**      | Text      | Sub-national administrative region                                      |
| **Way In**     | Text      | Mode or point of tourist entry, such as Land                            |
| **Year**       | Integer   | Observation year, ranging from 2005–2016                                |
| **Count**      | Numeric   | Number of tourist arrivals or entry events                              |
| **GDP**        | Numeric   | Gross Domestic Product associated with the country/region               |
| **Population** | Numeric   | Population associated with the designated area                          |

## 📈 Dashboard Visualizations

The dashboard includes multiple analytical views for identifying tourism and economic trends.

### 1. 🌍 Top 10 Country-wise Population

A horizontal bar chart comparing population values across the top 10 countries.

### 2. 🌦️ Season-wise Population

A bar chart showing population distribution across the four seasons.

* **Winter:** 17,298
* **Fall:** 16,786

### 3. 📅 Month-wise Population

A line chart displaying monthly variations and identifying seasonal patterns.

* **February:** 6,631
* Additional increases can be observed during **September and October**.

### 4. 💰 Country-wise GDP

A radar chart comparing GDP performance across selected countries, including:

* Austria
* Denmark
* Norway
* Switzerland
* United States

### 5. 🛬 Continent-wise Way In

A donut chart showing the distribution of tourist entry modes across different continents:

* Africa
* Asia
* Central America
* Europe
* North America
* Oceania
* South America

### 6. 📊 Year-wise Population

An area chart illustrating population/volume trends over the **2005–2016** period and highlighting long-term movements.

### 7. 🎛️ Interactive Slicers

The dashboard includes interactive slicers for:

* **Continent**
* **Month**

These slicers allow users to dynamically filter the dashboard and explore specific tourism trends.

## 🎯 Key Insights

* **Winter** records one of the highest seasonal population volumes.
* **February** represents a notable monthly peak.
* Tourism activity varies significantly across **countries and continents**.
* GDP comparisons highlight differences in economic performance among countries.
* Year-wise analysis provides a view of tourism and population trends between **2005 and 2016**.
* Interactive slicers enable users to perform **dynamic regional and monthly analysis**.
